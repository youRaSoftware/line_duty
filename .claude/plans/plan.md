# Line Duty — План разработки

> Аркада на разведении потоков (тема A «Диспетчер метро»): фигуры едут сверху вниз, игрок рисует им маршруты, ворота своего цвета принимают, касание двух фигур — конец забега.
> Стек: Flutter + Cubit (flutter_bloc) + get_it + go_router + Hive + Flame. Без сети.
> Спека: [my_docs/SPEC.md](../my_docs/SPEC.md) · UI-референс для скиллов: [shared/line_duty_ui_reference.md](../shared/line_duty_ui_reference.md)

## Что нужно сделать

### Фаза 1: Ощущения (ТЕКУЩАЯ)
- [x] **Шрифт с кириллицей (2026-09-22).** Space Grotesk был только латиницей, русский UI шёл системным фолбэком. Выбрана пара Unbounded (заголовок, большой счёт) + Golos Text (UI): `AppFonts.family` / `displayFamily`, лицензии в `LicenseRegistry`, спека § «Шрифт».
- [x] **Стыковка с воротами (2026-09-22).** Палец над *своими* воротами (или выше кромки на `GameTuning.gateDockMargin`) завершает маршрут входом в ворота (X — где палец, но целиком внутри ворот; Y — верхняя кромка), жест закрывается сам, ворота подсвечены (`GateComponent.armed`), линия поверх ворот не рисуется. Чужие ворота не стыкуют: линия идёт как есть, приезд туда — конец забега. Демо в меню тоже стыкуется. Логика жеста — `LineDutyGame.routeStart / routeMove / routeEnd`, тесты в `line_duty_game_test.dart`.
- [x] **Недорисованный маршрут — сделано 2026-09-23: конец маршрута → вниз, над своими воротами магнит; базы судятся по форме скина (свои ловят капсулой, чужие — по центру, ниже ряда — мимо).** Исходное предложение:
  - Сейчас: после последней точки фигура едет **строго вниз** (как без маршрута), а не по направлению последнего отрезка (сейчас). Правило для игрока: «маршрут — временное отклонение, без него фигура едет вниз». У конца маршрута рисовать короткий пунктирный «хвост» вниз, чтобы было видно, куда она поедет.
  - Приезд в промежуток между воротами — решено 2026-09-22: фигура попадает в ближайшие ворота, которые задевает краем (`gateCatchSlack`); раньше центр в 20-единичном зазоре давал «Не те ворота» даже когда фигура визуально стояла на своих воротах (баг со скриншота).
  - Отклонено: остановка фигуры в конце маршрута (парковка ломает давление спавна), продолжение по последнему отрезку (непредсказуемо, «бесконечная» траектория).
- [ ] **Разрез маршрута (предложение 2026-09-22).** Палец не на фигуре пересекает линию маршрута → маршрут усекается в точке пересечения (настоящее пересечение отрезков, не близость), хвост отваливается с анимацией (0.3–0.4 с: гаснет, сползает вниз), искра в точке среза, звук «щёлк» (в `gen_placeholder_audio.py`), стыковка снимается. Рекомендуемый вариант — **разрез с перенаправлением**: дальнейший путь пальца становится продолжением маршрута от точки среза (стыковка к воротам как обычно); отпустил сразу — маршрут кончается в срезе. Первое пересечение захватывает жест, дальше линии не режутся. Альтернатива — «просто ножницы» (только обрыв, новый маршрут отдельно от фигуры). Зависит от правила «конец маршрута → вниз», делать вместе.
- [x] Сохранение забега после выхода из приложения (2026-09-25): `RunSnapshot`/`RunRepository`/`runBox`, `capture/restore` в движке, снимок при уходе в фон и в меню, «Продолжить · счёт» и «Новый забег» в меню

## Бэклог / идеи
- Цвета ворот в HUD как легенда для дальтоников
- Режим «ночная смена»: спавны и ворота меняются местами
- Планшет: ограничить ширину поля, как `GameForm.contentMaxWidth` в WasDrop
- Город: покачивание корпуса автобуса на поворотах (спека § 4.1)
- Сад: раскрытие крыльев при подборе бонуса
- Бонусы: свой звук подбора (сейчас `deliver`), пикапы из бэклога спеки (замедление, призрак, магнит, волна)
- Лента тем: 5 карточек не помещаются в ширину — сейчас прокрутка, можно уменьшить карточки или показать стрелку
- Нативный сплэш `0D131E` — если дефолтом станет светлая тема, будет вспышка при старте
