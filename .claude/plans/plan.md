# Line Duty — План разработки

> Аркада на разведении потоков (тема A «Диспетчер метро»): фигуры едут сверху вниз, игрок рисует им маршруты, ворота своего цвета принимают, касание двух фигур — конец забега.
> Стек: Flutter + Cubit (flutter_bloc) + get_it + go_router + Hive + Flame. Без сети.
> Спека: [my_docs/SPEC.md](../my_docs/SPEC.md) · UI-референс для скиллов: [shared/line_duty_ui_reference.md](../shared/line_duty_ui_reference.md)

Чужие ворота не стыкуют: линия идёт как есть, приезд туда — конец забега. Демо в меню тоже стыкуется. Логика жеста — `LineDutyGame.routeStart / routeMove / routeEnd`, тесты в `line_duty_game_test.dart`.
- [ ] **Недорисованный маршрут (предложение, обсуждается 2026-09-22).**
