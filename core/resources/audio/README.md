# Звуки

Все файлы синтезированы `script/gen_placeholder_audio.py` (stdlib Python, без лицензий). При замене на настоящие сохранять имена: `core/lib/services/audio_service.dart` ссылается на них.

| Файл | Событие |
|---|---|
| `sfx_tap.wav` | нажатие кнопки |
| `sfx_draw.wav` | палец лёг на фигуру (начало маршрута) |
| `sfx_deliver.wav` | фигура въехала в свои ворота |
| `sfx_warn.wav` | кольцо сближения |
| `sfx_crash.wav` | столкновение |
| `sfx_record.wav` | столкновение с новым рекордом |
